# 顧客分析機能 - 機能仕様書

## 概要

宿泊施設の予約データ（CSV形式）をアップロードし、AIによる自動分析とマーケティングインサイトを生成する機能です。

**使用AIモデル**: Gemini 2.5 Flash-Lite

## 機能仕様

### 1. CSVファイルアップロード

#### 1.1 対応フォーマット

**ファイル形式**
- ファイル拡張子: `.csv`
- エンコーディング: 自動判別（UTF-8、Shift_JIS、CP932、EUC-JP、ISO-2022-JP）
- 最大ファイルサイズ: FastAPIデフォルト設定に準拠

**CSV構造**
- ヘッダー行: 必須
- データ形式: カンマ区切り（RFC 4180準拠推奨）

**推奨されるカラム構成**

| カラム名例 | 説明 | データ型 | 必須 |
|-----------|------|---------|------|
| 予約ID / 予約番号 | 一意の予約識別子 | 文字列 | 推奨 |
| 予約日 / 予約受付日 | 予約を受け付けた日付 | 日付 | 任意 |
| 宿泊日 / チェックイン日 | 宿泊開始日 | 日付 | 推奨 |
| プラン名 / プラン | 予約されたプラン名称 | 文字列 | 推奨 |
| 合計金額 / 料金 / 価格 | 予約の合計金額 | 数値 | 推奨 |
| ステータス / 状態 | 予約のステータス（確定/キャンセル等） | 文字列 | 推奨 |

**日付フォーマット**
以下の形式に対応:
- `YYYY/MM/DD` (例: 2024/12/01)
- `YYYY-MM-DD` (例: 2024-12-01)
- ISO 8601形式

**CSV例**
```csv
予約ID,予約日,宿泊日,プラン名,合計金額,ステータス
B0001,2024/01/15,2024/02/20,素泊まりプラン,8000,確定
B0002,2024/01/20,2024/03/10,朝食付きプラン,12000,キャンセル
B0003,2024/01/25,2024/04/05,夕朝食付きプラン,18000,確定
```

#### 1.2 エンコーディング自動判別

システムは以下の優先順位でエンコーディングを自動判別します:

1. chardetライブラリによる自動検出
2. UTF-8
3. Shift_JIS
4. CP932（Windows版Shift_JIS）
5. EUC-JP
6. ISO-2022-JP

各エンコーディングで読み込みを試行し、成功したものを使用します。

### 2. AIスキーマ推定（Smart Schema Inference）

#### 2.1 機能概要

Gemini 2.5 Flash-LiteがCSVのカラム名とサンプルデータを解析し、以下のフィールドを自動的に特定します。

**推定対象フィールド**

| フィールド名 | 説明 | 用途 |
|------------|------|------|
| `booking_date` | 予約日 | リードタイム計算 |
| `stay_date` | 宿泊日 | 期間分析、曜日別分析 |
| `plan_name` | プラン名 | 人気プラン分析 |
| `total_price` | 合計金額 | 価格統計 |
| `status` | 予約ステータス | キャンセル率計算 |

#### 2.2 推定ロジック

**入力データ**
- カラム名一覧
- サンプルデータ（先頭10行）

**AIプロンプト**
```
あなたは宿泊予約データ分析の専門家です。
提示されたCSVデータから、以下の情報を表すカラム名を特定し、
正確なJSON形式で返してください。

- booking_date (予約日)
- stay_date (宿泊日)
- plan_name (プラン名)
- total_price (合計金額)
- status (予約ステータス - キャンセル判定用)

※データの中身（日付フォーマットや値の傾向）から文脈を読んで判断すること。
該当するカラムがない場合は null を返してください。
```

**出力形式**
```json
{
  "booking_date": "予約日",
  "stay_date": "宿泊日",
  "plan_name": "プラン名",
  "total_price": "合計金額",
  "status": "ステータス"
}
```

### 3. 統計情報計算

#### 3.1 基本統計

| 指標名 | 説明 | 計算方法 |
|--------|------|---------|
| 総レコード数 | CSVの全レコード数 | `len(df)` |
| 期間 | データの対象期間 | 宿泊日の最小値〜最大値 |

#### 3.2 キャンセル分析

**キャンセル率**
```
キャンセル率(%) = (キャンセル件数 / 総予約件数) × 100
```

**キャンセル判定基準**
ステータスカラムに以下のキーワードが含まれる場合、キャンセルと判定:
- `キャンセル`
- `cancel`
- `cancelled`
- `canceled`
- `取消`

**直前キャンセル率**
```
直前キャンセル率(%) = (宿泊日の7日前以降のキャンセル / 全キャンセル) × 100
```

**出力形式**
```json
{
  "total_bookings": 1000,
  "cancelled_bookings": 150,
  "cancellation_rate_percent": 15.0,
  "last_minute_cancellation_rate_percent": 40.0
}
```

#### 3.3 予約行動分析

**平均リードタイム**
```
リードタイム = 宿泊日 - 予約日
平均リードタイム = mean(全リードタイム)
```

単位: 日

#### 3.4 プラン分析

**人気プランTop5**

プラン名ごとの予約件数を集計し、上位5件を返却します。

**出力形式**
```json
{
  "素泊まりプラン": 300,
  "朝食付きプラン": 250,
  "夕朝食付きプラン": 180,
  "特別ディナーコース": 120,
  "ファミリープラン": 100
}
```

#### 3.5 曜日別分析

**曜日別予約数**

宿泊日の曜日ごとに予約件数を集計します。

**出力形式**
```json
{
  "Monday": 120,
  "Tuesday": 100,
  "Wednesday": 110,
  "Thursday": 95,
  "Friday": 180,
  "Saturday": 250,
  "Sunday": 145
}
```

#### 3.6 価格統計

| 指標 | 説明 | 計算方法 |
|------|------|---------|
| 平均価格 | 全予約の平均金額 | `mean(total_price)` |
| 最小価格 | 最も安い予約金額 | `min(total_price)` |
| 最大価格 | 最も高い予約金額 | `max(total_price)` |
| 中央値 | 価格の中央値 | `median(total_price)` |

### 4. AIマーケティングインサイト生成

#### 4.1 機能概要

統計情報を基に、Gemini 2.5 Flash-Liteが実践的なマーケティング提案を生成します。

#### 4.2 インサイト内容

**含まれる要素**

1. **ターゲット層の特徴**
   - 予約行動パターンの分析
   - 人気プランからの顧客傾向把握

2. **現状の課題**
   - キャンセル率の評価
   - リードタイムの傾向分析
   - 稼働率の偏り

3. **推奨アクション**
   - 具体的なマーケティング施策
   - 価格戦略の提案
   - プロモーション施策の提案

#### 4.3 AIプロンプト

```
あなたは宿泊業界に精通したマーケティングアナリストです。
データから実践的なインサイトを導き出し、具体的な施策を提案してください。

以下の観点を含めてください：
1. ターゲット層の特徴
2. 現状の課題（キャンセル率、リードタイムなど）
3. 推奨アクション（具体的なマーケティング施策）
```

#### 4.4 出力例

```
【顧客分析インサイト】

平均リードタイムが21.5日と比較的長く、お客様は計画的に予約する傾向があります。
キャンセル率は15%で業界平均並みですが、そのうち40%が直前キャンセルであり、
機会損失が発生しています。

人気プランは「素泊まり」「朝食付き」が上位を占め、シンプルなプランが好まれています。
週末（金〜日）の予約が平日の1.5倍となっており、週末需要が高いことが分かります。

【推奨アクション】
1. 早期予約割引の強化: 30日前予約で10%オフなど、計画的な予約を促進
2. 直前キャンセル対策: 前払い制度の導入、7日前からのキャンセル料率引き上げ
3. 平日稼働率向上: 平日限定プランの展開、ビジネス客向けプロモーション
4. 人気プランの拡充: 朝食のバリエーション増加、地域特産を活かした新プラン開発
```

## API仕様

### エンドポイント: POST /api/analysis/upload-csv

#### リクエスト

**Content-Type**: `multipart/form-data`

**パラメータ**

| パラメータ名 | 型 | 必須 | 説明 |
|------------|-----|------|------|
| `hotel_id` | integer | ✅ | 宿泊施設ID |
| `file` | file | ✅ | CSVファイル |

**curlコマンド例**
```bash
curl -X POST "http://localhost:8000/api/analysis/upload-csv" \
  -F "hotel_id=1" \
  -F "file=@customer_data.csv"
```

#### エラーレスポンス

**400 Bad Request** - CSVファイル以外がアップロードされた場合
```json
{
  "detail": "CSVファイルをアップロードしてください"
}
```

**404 Not Found** - 指定された宿泊施設が存在しない場合
```json
{
  "detail": "宿泊施設が見つかりません"
}
```

**500 Internal Server Error** - 分析処理中にエラーが発生した場合
```json
{
  "detail": "分析エラー: [エラー詳細]"
}
```

    ↓

### 処理時間

| データ件数 | 推定処理時間 |
|-----------|------------|
| 100件 | 3〜5秒 |
| 1,000件 | 5〜10秒 |
| 10,000件 | 10〜20秒 |

※ネットワーク状況やAPI応答速度により変動します

### APIコスト

**Gemini 2.5 Flash-Lite料金**
- 入力: $0.0001 / 1K tokens
- 出力: $0.0004 / 1K tokens

**1回の分析あたりの推定コスト**
- スキーマ推定: 約500 tokens → $0.0002
- インサイト生成: 約1000 tokens → $0.0008
- **合計**: 約$0.001 / 分析

### ファイルアップロード

- ✅ ファイル拡張子の検証（.csvのみ許可）

- ✅ 統計情報のみデータベースに保存

- ⚠️ 現在は認証なし

## 制約事項

### 現在の制約

1. **CSVフォーマット**
   - カンマ区切りのみ対応（TSV非対応）
   - マルチライン値の扱いに制限あり

2. **データサイズ**
   - FastAPIのデフォルト制限に準拠
   - 大規模データ（100万行以上）は未検証

3. **スキーマ推定**
   - 推定精度はデータの品質に依存
   - カラム名が不明確な場合、誤推定の可能性

4. **AIインサイト**
   - 日本語のみ対応
   - 業種は宿泊業に特化
